# SkillScan AI

SkillScan AI is a mobile-first, AI-powered platform that automates video-based job interviews to assess the job readiness of blue-collar and polytechnic-skilled candidates.

---

## Features

- AI-powered interview simulation
- Multilingual interaction (Hindi, Kannada, English)
- Candidate scoring and classification
- Result dashboard
- Mobile-first interface

---

## Tech Stack

- HTML
- CSS
- JavaScript
- VS Code
- GitHub Pages

---

## How to Run

1. Download or clone the repository
2. Open the project folder in VS Code
3. Make sure all files are in the same folder
4. Install the Live Server extension
5. Right-click `index.html`
6. Select **Open with Live Server**
7. Start the interview simulation

---

## Project Goal

To provide scalable, accessible, and AI-powered workforce screening for blue-collar and polytechnic-skilled candidates across India.
